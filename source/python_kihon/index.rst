Pythonの基本 —— 困ったらここに戻るページ
==========================================

このページの使い方
------------------

このページは **覚えるためではなく、引くための1ページ** です。

- 各回の冒頭10分「今日使う文法のミニ復習」は、このページの該当箇所を見ながら行います
- 写経中に「これ何だっけ?」となったら、ここに戻ってくる
- 全部を最初に読む必要はありません

どの文法がどの月で登場するかは、ページ末尾の対応表を見てください。

IDLEの基本操作
--------------

- 白い「シェル」( ``>>>`` が出る画面)は電卓・実験用。1行打つとすぐ結果が返る
- プログラムは「File → New File」で開くエディタに書き、 **F5** で実行する
  (保存を求められたら半角英数字の名前で ``.py`` として保存)
- 保存場所はデスクトップの ``python-benkyokai`` フォルダに統一する

.. tip::

   シェルは「試す場所」、エディタは「作る場所」。
   新しい命令に出会ったら、まずシェルで1行試してみるのが上達の近道です。

変数と型
--------

変数は「値に付ける名前」。 ``=`` は「等しい」ではなく「右の値を左の名前に入れる」です。

.. code-block:: python

   uriage = 12800          # 整数(int)
   ritsu = 0.1             # 小数(float)
   shiten = "東京"          # 文字列(str)。引用符で囲む
   print(uriage * 3)       # 38400

型がわからなくなったら ``type()`` で確認できます。

.. code-block:: python

   print(type(uriage))     # <class 'int'>

型の変換(10月の「汚れ落とし」で主役になります):

.. code-block:: python

   int("12800")            # 文字列 → 整数
   str(12800)              # 整数 → 文字列
   float("0.1")            # 文字列 → 小数

.. note::

   ``"12800"`` (文字列)と ``12800`` (数値)は別物です。
   ``"12800" + 100`` はエラーになります。CSVから読んだ数字が計算できないときは、
   たいてい「文字列のまま」なのが原因です。

文字列
------

.. code-block:: python

   name = "請求書_A社_202606.pdf"

   "請求書" in name                    # 含むか? → True(8月で使う)
   name.replace(".pdf", "")           # 置き換え → "請求書_A社_202606"
   name.split("_")                    # 分解 → ["請求書", "A社", "202606.pdf"]
   name.startswith("請求書")           # 〜で始まるか? → True

   f"合計は{uriage}円です"             # f-string:文字列に変数を埋め込む

.. tip::

   10月に出てくる ``df["売上"].str.replace(",", "")`` は、
   この ``replace`` を「表の1列まるごと」に適用したものです。

リスト
------

複数の値を順番に並べて入れる箱です。8月以降は、取得した本の情報を順番に保存するために使います。

.. code-block:: python

   sizes = [3200, 45, 900, 12]

   len(sizes)              # 個数 → 4
   sizes.append(60)        # 末尾に追加
   sizes.sort()            # 小さい順に並べ替え
   sizes.sort(reverse=True)  # 大きい順
   sizes[0]                # 最初の要素(番号は0から!)
   sizes[:3]               # 最初の3個(トップ3の取り出しに使う)

辞書
----

「名前(キー)→ 値」の対応表。8月の「種類別に数える」で主役になります。

.. code-block:: python

   counts = {".pdf": 12, ".xlsx": 7}

   counts[".pdf"]                     # 取り出し → 12
   counts[".png"] = 3                 # 追加
   counts.get(".txt", 0)              # 無ければ0を返す(エラーにならない取り出し)

「数える」定番パターン(丸暗記でOK):

.. code-block:: python

   counts = {}
   for item in [".pdf", ".xlsx", ".pdf"]:
       counts[item] = counts.get(item, 0) + 1
   # → {'.pdf': 2, '.xlsx': 1}

if文 —— 条件で分ける
--------------------

.. code-block:: python

   if uriage >= 100000:
       print("大口です")
   elif uriage >= 50000:
       print("中口です")
   else:
       print("小口です")

- 条件の行末に ``:`` を忘れない
- 中身は **半角スペース4つ** 下げる(この字下げがPythonの文法そのもの)

比較と組み合わせ:

.. code-block:: python

   a == b        # 等しい(=が2つ!)
   a != b        # 等しくない
   a >= b        # 以上
   "請求書" in name          # 含む
   4 <= month and month <= 6  # かつ(10月の「4〜6月に絞る」)

for文 —— 繰り返す
-----------------

.. code-block:: python

   for f in files:             # リストの中身を1つずつ取り出す
       print(f)

   for i in range(5):          # 0,1,2,3,4 と5回まわす
       print(i)

   for title, price in rows:   # 「1行=複数の値」をまとめて受け取る（8月）
       print(title, price)

if文と同じく、行末の ``:`` と字下げがセットです。
**「forで1つずつ取り出し、ifで選り分ける」** ——この組み合わせが8・9月の背骨です。

import —— 道具箱を開ける
------------------------

.. code-block:: python

   from pathlib import Path    # 標準ライブラリ:インストール不要(8月)
   import csv                  # 同上
   import pandas as pd         # 外部ライブラリ:pipでインストールが必要(10月〜)

- **標準ライブラリ** :Pythonに最初から付いてくる( ``pathlib``, ``csv``, ``datetime``, ``shutil`` )
- **外部ライブラリ** :あとから入れる( ``requests``, ``bs4``, ``pandas``, ``matplotlib`` )。
  インストールはIDLEの中ではなく、コマンドプロンプト(Macはターミナル)で
  ``python -m pip install ライブラリ名``
- ``as pd`` は「以後 ``pd`` と呼びます」という略称の宣言。 ``pd.read_csv`` のように使う

エラーの読み方
--------------

エラーは叱られているのではなく、 **Pythonからの報告書** です。長くても
**最後の1行だけ** 読めばだいたいわかります。

.. list-table::
   :header-rows: 1
   :widths: 30 70

   * - 最後の1行
     - よくある原因
   * - ``IndentationError``
     - 字下げがずれている(スペースの数を確認)
   * - ``SyntaxError``
     - 書き間違い。 **全角スペース・全角記号の混入** が最多。 ``:`` 忘れも
   * - ``FileNotFoundError``
     - ファイルの保存場所違い。 ``.py`` とデータが同じフォルダにあるか確認
   * - ``NameError``
     - 変数名・関数名の打ち間違い(大文字小文字も区別されます)
   * - ``TypeError``
     - 型の不一致。文字列と数値を足そうとした、など
   * - ``ModuleNotFoundError``
     - ライブラリが未インストール。pipを実行したか確認

.. tip::

   エラーが出たら、最後の1行にあるエラー名と、示された行番号を確認します。
   直前に変更した箇所も見直し、原因を1つずつ切り分けましょう。

文法と各月の対応表
------------------

.. list-table::
   :header-rows: 1
   :widths: 30 70

   * - 文法
     - 主に登場する月
   * - 変数・print
     - 全部の月(5月の基礎①から)
   * - for文・if文
     - 8月（1ページの収集）から毎月
   * - 文字列( ``in`` / ``replace`` )
     - 8月（価格の整形）、10月（データの整形）
   * - リスト( ``append`` / ``sort`` )
     - 8月（取得結果の保存）、9月（JSONから行への変換）
   * - 辞書
     - 9月（APIのパラメーターとJSON）
   * - 型変換( ``int()`` / ``astype`` )
     - 8月（価格の数値化）、10月（pandasによる型変換）
   * - import(標準ライブラリ)
     - 8・9月（ ``csv`` ）
   * - import(外部ライブラリ)+pip
     - 8月（ ``requests`` / ``BeautifulSoup`` ）、10月（ ``pandas`` ）、
       11月（ ``Playwright`` / ``matplotlib`` ）
